# Security Policy

## Preferred reporting method
Please use GitHub Security Advisories for this repository:

https://github.com/ToyLantis-Manufacturers-and-Mechanics/Jet-Plane/security/advisories

This provides a private channel for reporting and coordinated disclosure.

## Alternative (if you cannot access Security Advisories)
Open a new GitHub issue titled: `SECURITY: <short summary>`

- Do NOT include exploit code, credentials, or other sensitive data in the public issue body.
- Provide a concise summary and safe reproduction steps.
- After you open the issue, we will request a private channel (via the Advisory or by asking you to redact sensitive details and share them privately via GitHub).

## What to include
- A short description of the vulnerability
- Steps to reproduce (minimal, safe reproduction preferred)
- Impact (what an attacker can do)
- Any suggested mitigation or fixes

## Do not post
- Passwords, private keys, customer data, or full exploit payloads in public issues.

## Response
We will acknowledge incoming reports via the Security Advisory or issue thread; please allow up to 5 business days for an initial response. We will coordinate fixes and disclosure through the Advisory or private channel.

Thank you for responsibly disclosing security issues to ToyLantis Manufacturers and Mechanics.
